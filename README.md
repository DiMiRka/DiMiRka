**[SFMShop](https://github.com/DiMiRka/SFMShop)**: бэкенд интернет магазина на FastAPI
- PostgreSQL с репликой для чтения, Redis, RabbitMQ, MongoDB
- ИИ-ассистент на Claude API (tool calling, structured output, права проверяет сервер, а не модель)
- мониторинг: Prometheus, Grafana, Alertmanager с уведомлениями в Telegram

- 200+ тестов (покрытие 98%)

**[dimirka_poker_bot](https://github.com/DiMiRka/dimirka_poker_bot)**: асинхронный Telegram бот для учёта и анализа статистики домашних покерных игр
